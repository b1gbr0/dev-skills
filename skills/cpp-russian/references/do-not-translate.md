# Что остаётся латиницей

Смотреть при сомнении, переводить ли термин. Если он есть в списках ниже — не переводить.

## 1. Всё, что копируется в исходник

Ключевые слова и спецификаторы, идентификаторы стандартной библиотеки, идентификаторы проекта, флаги компилятора, тексты диагностик, названия стандартов. Полный принцип — в SKILL.md, раздел «Никогда не переводится».

Отдельно: **имя контейнера или типа из stdlib не заменяется русским словом никогда**, даже если русское слово существует и точно передаёт смысл. Русское слово может стоять рядом как родовое пояснение — «словарь `std::map`», — но не вместо идентификатора.

## 2. Акронимы

Расшифровывать при первом упоминании можно, использовать расшифровку как имя — нельзя.

| Акроним | Расшифровка (для пояснения) | Почему не переводится |
|---|---|---|
| RAII | resource acquisition is initialization | Имя идиомы; расшифровка объясняет смысл, но не заменяет название. |
| SFINAE | substitution failure is not an error | Русская калька расшифровки не опознаётся как имя механизма. |
| CRTP | curiously recurring template pattern | Русского названия не сложилось; кальки не употребляются на практике. |
| ODR | one definition rule | Допустимо «правило одного определения (ODR)»; акроним не переводится. |
| ADL | argument-dependent lookup | Допустимо «поиск, зависящий от аргументов (ADL)». |
| RVO / NRVO | (named) return value optimization | Устойчивого русского сокращения нет. |
| UB | undefined behavior | Понятие переводится — «неопределённое поведение»; акроним остаётся латиницей. |
| POD | plain old data | Термин выведен из стандарта в C++20; употребляется как «POD-тип». |

## 3. Категории значений

`lvalue`, `rvalue`, `glvalue`, `prvalue`, `xvalue` — латиницей всегда. Их не транслитерируют даже русскоязычные справочники. Формы вида «глзначение», «прзначение», «л-значение» не употребляет никто, и опознать их невозможно.

Допустимые гибриды: «rvalue-ссылка», «ссылка rvalue», «категория значения».

## 4. Термины без устоявшегося русского эквивалента

Оставлять латиницей и, при необходимости, пояснять по-русски отдельным предложением:

`SFINAE`, `CRTP`, `most vexing parse`, `name mangling`, `lock-free`, `promise type`, `awaitable`, `std::span`, `std::string_view`, `constexpr`/`consteval`/`constinit` (ключевые слова), `co_await`/`co_yield`/`co_return` (ключевые слова).

## 5. Запрещённые самоделки

Формы, которые выглядят правдоподобно, но вредят. Для каждой указано, чем именно.

| Плохо | Правильно | Чем вредно |
|---|---|---|
| карта (о `std::map`) | словарь `std::map`, ассоциативный контейнер `std::map` | Перевод имени типа по бытовому значению слова map. В проекте с картографией, навигацией или игровыми уровнями «карта» неотличима от предметной сущности — собеседник ищет доменный класс и не находит. |
| мапа, в мапе | словарь `std::map` | Жаргон с русским склонением латинского корня; в документации неуместен. |
| универсальная ссылка | forwarding reference, передающая ссылка | Неформальное название. Стандартный термин forwarding reference точнее указывает на ссылку, поведение которой зависит от вывода типа аргумента. |
| «подстановка неудачи не является ошибкой» как название | SFINAE | Это расшифровка акронима, а не имя механизма. По такой фразе ничего не найти. |
| «любопытно повторяющийся шаблон» | CRTP | Дословная калька, которой не пользуется никто. |
| замувить, сделать мув | переместить, применить `std::move` | Латинский корень с русскими окончаниями. |
| отнаследоваться | унаследовать, наследуется от | Просторечие. |
| глзначение, прзначение | glvalue, prvalue | Транслитерация того, что не транслитерируют даже справочники. |
| элизия копий | пропуск копирования | «Элизия» ничего не сообщает читателю, не знакомому с лингвистическим значением слова. |
| неблокирующий (о `lock-free`) | lock-free | Смешивается с неблокирующим вводом-выводом — это разные вещи. |
| разумный указатель | умный указатель | «Умный указатель» — устоявшийся термин; вариации не опознаются. |
| куча (о динамической памяти) в незнакомом контексте | динамическая память, свободная память | «Куча» употребима, но в проекте с предметной «кучей» (сортировка, склад, агрегация) создаёт ту же коллизию, что и «карта». Проверяй контекст. |

## 6. Правило на случай, которого нет в списках

Если для термина не находится устоявшегося русского эквивалента:

1. Оставь латиницу.
2. Поясни смысл отдельным русским предложением.
3. Скажи прямо, что устоявшегося перевода нет.

Не изобретай перевод. Непереведённый термин собеседник опознает и найдёт в документации; выдуманный — не найдёт нигде и потратит время на выяснение, что имелось в виду.
