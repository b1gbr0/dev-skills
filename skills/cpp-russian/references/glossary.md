# Глоссарий терминов C++

Канонические русские эквиваленты с определениями. Колонка «Форма» — перевод / транслит / латиница / гибрид (см. правило трёх форм в SKILL.md).

Определение — одно предложение, пригодное для повторного использования в объяснении или комментарии.

> **О достоверности.** Термины из разделов «Базовые понятия» — «Современный C++» сверены с русскоязычным учебным источником (metanit.com/cpp/tutorial) и совпадают с устоявшейся практикой. Разделы «Многопоточность», «Поведение программы», «Свойства типов» собраны по фрагментам ru.cppreference.com, полученным через поиск (прямой доступ к сайту был заблокирован), и совпадают с общепринятой практикой, но дословными цитатами не подтверждены. Спорные случаи вынесены в отдельный раздел в конце.

## Спорные термины

Здесь в русском языке сосуществуют два варианта. Правило: **выбери один и держись его в пределах документа**, при первом упоминании дай английский оригинал в скобках.

| EN | Варианты | Рекомендация |
|---|---|---|
| instantiation | инстанцирование / создание экземпляра | «Инстанцирование» — оно однозначно относится к шаблонам, тогда как «создание экземпляра» путается с созданием объекта. |
| copy elision | пропуск копирования / элизия копий | «Пропуск копирования» — понятно без знания лингвистического значения слова «элизия». |
| forwarding reference | передающая ссылка / перенаправляющая ссылка | Лучше оставить латиницей. «Универсальная ссылка» — устаревший термин, заменённый комитетом именно из-за неточности. |
| deduction guide | правило вывода / руководство по выводу | Единого варианта нет; при первом упоминании обязательно дать оригинал. |
| pack expansion | развёртывание пакета / расширение пакета | «Развёртывание» ближе по смыслу к тому, что происходит. |
| type trait | свойство типа / типаж | «Свойство типа» — понятнее; «типаж» встречается, но требует пояснения. |
| lock-free | без блокировок / lock-free | Лучше латиницей: «неблокирующий» смешивается с неблокирующим вводом-выводом. |
| unspecified behavior | неуточнённое / неспецифицированное поведение | Любой, но не путать с неопределённым поведением (undefined behavior). |
